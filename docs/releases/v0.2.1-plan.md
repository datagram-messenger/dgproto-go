# v0.2.1 release plan

## Goal and baseline

Prepare a focused, backward-compatible patch release from `v0.1.3`
(`6dc2a86`). The release addresses four items from the
`V1_IMPLEMENTATION_PLAN.md` task list that are safe to ship without wire,
API, or dependency changes:

1. **Terminology:** replace "whitelist" with "allowlist" in the
   `ServerConfig.AllowedClients` godoc comment, consistent with the rest of
   the public documentation.
2. **Constructor panic coverage:** add explicit regression tests for the
   documented nil-argument panics in `NewTCPTransport` and `NewConnection`,
   freezing the panic contract before v1 (Phase 3 task: "Decide and freeze
   nil-constructor behavior").
3. **Production timeout guidance:** add a "Production timeout guidance"
   section to `docs/guides/getting-started.md` with a reference table and
   the `ReadTimeout`/liveness-window constraint (Phase 3 task: "Define
   production timeout guidance and safe defaults/examples for
   internet-facing use").
4. **CI/release supply-chain hardening:** pin all `actions/checkout` and
   `actions/setup-go` uses in `ci.yml` and `release.yml` to reviewed
   immutable commit SHAs with version comments, eliminating mutable major
   tags (Phase 6 task: "Pin workflow actions and installed tools to reviewed
   immutable versions/commits").

## Scope

- `server.go`: godoc `AllowedClients` comment: "whitelist" → "allowlist".
- `tcp_test.go`: add `TestNewTCPTransportNilPanics` and
  `TestNewConnectionNilPanics` covering nil transport and nil session.
- `docs/guides/getting-started.md`: add "Production timeout guidance"
  section with a reference table and liveness-window constraint note.
- `.github/workflows/ci.yml`: pin all four `actions/checkout` and
  `actions/setup-go` steps to SHA `11d5960…` and `40f1582…` respectively.
- `.github/workflows/release.yml`: pin both `actions/checkout` steps to
  SHA `11d5960…`; pin `actions/setup-go` in the validate job to SHA
  `40f1582…`; update dispatch default tag to `v0.2.1`.

## Compatibility

- No exported function signature, wire-format, cryptographic, dependency,
  or interoperability-vector changes.
- No behavioral change to any public API, error sentinel, or lifecycle
  guarantee.
- The godoc and guide edits are prose-only corrections.
- The new tests exercise existing documented behavior; they do not change it.
- The workflow SHA pins are operationally equivalent to the previous mutable
  major-tag references at the time of this release.

## Rollback

Never move or overwrite the published tag. If a regression is confirmed,
revert the affected commit on `main`, rerun all release gates, and publish
a new patch version.
